# Script Studio

After `npm run setup`, start `npm run gui` and open <http://127.0.0.1:18994/>. The server binds to loopback. Set `NARRATIVE_GUI_PORT` to change the port.

Write a script, choose a reading pace and mouth strength, then choose the imported gesture plus idle or idle alone. The gesture plays once and crossfades into idle over half a second. Each later idle wrap crossfades over 0.3 seconds instead of jumping to the first frame. The idle in that loop is PoseLab's Neutral Idle, the calm 8.1s clip, not the imported Happy Idle swing. Set `idleClip` to `imported` to loop the idle file from setup instead. `idleCalm` eases that imported clip when a step exceeds 2°; set it to false to keep the authored swing. Reactivity defaults to still, which keeps that gesture-and-idle performance. Subtle and lively add camera look, beat accents, and tighter mouth shapes on top of the PoseLab clip. See [Reactive motion](REACTIVE-MOTION.md). Camera options are cuts, medium, close-up, a directed take with a selected reveal word, or a storyboard of 2–8 script sections separated by blank lines. Choose landscape or portrait, apply changes to preview, and save or render. The silent MP4 and SRT/VTT links appear when rendering finishes.

The script compiler estimates word timings and maps written vowel groups to five VRM mouth expressions. It does not align to recorded speech. Imported PoseLab body poses continue across camera cuts. The directed preset adds a bounded lens creep, physical push, partial release, seeded handheld movement, and depth focus path. It assumes the avatar's face is near the configured stage depth and does not track a moving head. Episode JSON can set `camera.follow` on a shot when a close-up needs the lens to lag the head. `pitchDegrees` on that camera, or on the episode, pitches the lens up after follow. `liftDegrees` on the performance or the episode pitches the head up instead, so the fringe moves with the skull. Omit either and that part stays put.

Music close-ups (groove nods, blinks, breath, section mood, idle mouth) are episode JSON, not Performance controls yet. See [Reactive motion](REACTIVE-MOTION.md). A silent hold after a short line still will not blink unless that episode sets `reactivity.eyes`.

Drafts and render jobs are local under `out/studio/`. The editor allows one render at a time. An incomplete storyboard may be saved, then finished later. A completed job records its exact episode JSON and render receipt. See [subtitle sidecars](SUBTITLES.md) for re-export from a saved episode.

Ctrl+C or SIGTERM stops the GUI and signals the in-progress render, including a render that was still running when Script Studio was opened again. Only a live `scripts/render.mjs` process counts as that render; an unrelated reused process id does not block the next take.
